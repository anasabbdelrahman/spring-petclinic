# Vet Pagination Brownfield Migration - PR Description

**Preserved.** Existing successful pagination behavior remains unchanged: an absent page parameter and `page=1` return the first five vets, `page=2` returns the remaining vet, and `page=999` returns an empty table with HTTP 200. The `/vets` JSON endpoint, owner pagination behavior, templates, localized messages, sorting, caching, and unrelated modules were not changed. The migration also preserves the original page size of five and the one-based HTTP parameter to zero-based repository translation.

**Risked.** The change replaces the selected legacy pagination path with a validating path and maps every integer page below 1 to HTTP 400. The main risks were accidentally changing valid-page behavior, applying a broad exception handler, altering shared error-page content, or mishandling `Integer.MIN_VALUE`. Investigation revealed that `Integer.MIN_VALUE` previously produced HTTP 500 in the persistence layer rather than the initially assumed HTTP 200. The acceptance ledger was corrected before implementation. The legacy `unvalidated()` translation remains in place with no callers because Branch-by-Abstraction Phase 4 Remove requires production evidence and is intentionally still open.

**Mitigated.** The migration used four Branch-by-Abstraction iterations: characterize current HTTP behavior, extract the translation seam, implement the validating path without selecting it, and finally toggle the controller to the validated path. Fresh-session reviews after Iterations 2, 3, and 4 found the work appropriately scoped. Red contract tests demonstrated the three intended 500-to-400 changes before production code changed, while five additional contract tests protected unchanged behavior. Mutation-style failing witnesses failed exactly the expected tests, while focused tests, regression tests, two formatting passes, and the full build all passed, with 122 tests and no failures, errors, or skips. The final ledger records that AC-D1 is met while Phase 4 Remove remains open with its exact gap and trigger.
